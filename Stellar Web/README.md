# Stellar

Website for the Stellar WoW guild and gaming community. Plain HTML/CSS/JS on GitHub Pages.

## Setup
1. Open `script.js` and fill in `CONFIG` at the top: your Discord invite, and your server ID for the widget.
2. Search the HTML for `<!-- EDIT` comments: stats, schedule, rules, FAQ answers, footer links.

## Announcements
`announcements.json` holds the posts shown on the home and News pages. Right now it has placeholder posts.
The plan is for a small Discord bot to copy messages from the announcements channel into this file automatically.
